# DS-A2: Inference and Uncertainty

**Course:** Data Science  
**Assignment:** DS-A2 — Inference and Uncertainty

## Overview

This project explores statistical inference and uncertainty through simulation. It includes sampling distributions, confidence intervals, hypothesis testing, statistical power analysis, and counterexamples illustrating the effects of violated statistical assumptions.

## Repository Contents

- `DS_A2_Inference_Uncertainty_final.ipynb` — Jupyter notebook containing the analysis, simulations, and interpretations.
- `DS_A2_Inference_Uncertainty_final.pdf` — PDF report exported from the notebook.
- `DS-A2_power_simulation_results.csv` — Results of the statistical power simulations.
- `DS-A2_counterexample_results.csv` — Results of the assumption-violating counterexample simulations.
- `method_note.md` — Notes on the analytical methods.
- `AI_verification_log.md` — Record of AI assistance and verification.
- `README.md` — Project overview and file guide.

## Reproducibility

The notebook documents the simulation procedures and random seeds used for reproducibility. To reproduce the analysis, open the notebook in Jupyter Notebook or Google Colab and execute the cells in order.

## Data and Interpretation

The results are based on simulations and hypothetical data rather than patient-level observations. Findings should be interpreted within the assumptions and limitations described in the notebook.
